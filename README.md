修士1年。機械学習・画像認識の研究をしています。
主にPythonを使って、画像認識モデルやAIを使ったアプリケーションを作っています。
研究のほか、データ分析コンペや国際ハッカソンでの開発にも取り組んでいます。

## 🔬 研究

### 強化学習による画像分類

分類結果に応じた報酬を使って、画像認識モデルを学習する方法を研究しています。
報酬の与え方やクラス数によって、精度や学習の進み方がどう変わるかに関心があります。

### 古琴の減字譜認識・自動打譜

伝統楽器・古琴の譜面を画像から読み取り、演奏可能な音楽データへ変換するシステムを開発しました。
画像認識と生成AIを組み合わせ、譜面に省略されている演奏情報を補うことで、文化の継承や学習支援を目指した研究です。

### 顔と背景を考慮した表情認識

顔の表情だけでなく、周囲の状況も考慮して感情を推定するモデルを研究しました。
顔と背景の情報をどのように組み合わせるかを比較・検討しました。
